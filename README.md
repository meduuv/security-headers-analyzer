# Security Headers Analyzer

A dependency-free local browser tool for inspecting pasted HTTP response headers against common defensive security headers.

## Features
- CSP, HSTS, Referrer-Policy and Permissions-Policy
- MIME sniffing and clickjacking checks
- No uploads, APIs, tracking, or target requests
- Works from a local file

## Usage
Open index.html and paste raw response headers.
